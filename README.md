# JSB Manager

Application de préparation physique, judo, taïso et suivi des présences — Judo Sans Barrières.

Installable sur iPhone (Safari › Partager › Sur l'écran d'accueil) et utilisable hors ligne.
La base d'exercices n'est pas publiée ici : elle est importée sur l'appareil.
Les présences, licenciés et photos restent uniquement sur l'appareil.
